# Build guide

## 1. Kickoff

Read the game manual together and write down every scoring opportunity. Agree on
**one** primary strategy before sketching mechanisms.

## 2. Prototype

- Prototype the riskiest mechanism first.
- Timebox each prototype to a single meeting.
- Keep a photo log — prototypes are documentation.

## 3. Design review

Every subsystem gets a review with a checklist:

- [ ] Can it be repaired in under ten minutes?
- [ ] Does it fit within the frame perimeter?
- [ ] Are the fasteners accessible?
- [ ] Is the wiring protected from impacts?

## 4. Build

Tag every part with its subsystem. If a part cannot be explained to a new
member, it needs a note in the team wiki.

## 5. Competition

Bring spares, a printed pit checklist, and a laptop with the latest code. Log
every match in the team wiki the same day, while details are fresh.
